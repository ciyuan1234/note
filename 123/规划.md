## 一、嵌入式有主流路线

| 路线分类             | 方向定位                               | 就业岗位               |
| :--------------- | :--------------------------------- | :----------------- |
| 1. 传统单片机裸机       | 51/STM32/ESP32，家电、工控、小家电           | 单片机开发、硬件嵌入式        |
| 2. RTOS 实时系统     | FreeRTOS、RT-Thread、LiteOS，工业控制、物联网 | RTOS 嵌入式工程师        |
| 3. Linux 应用嵌入式   | Linux 系统编程、网络、后台服务，物联网、网关          | Linux 应用开发         |
| 4. **车载嵌入式（主攻）** | 车载 Linux、CAN/Ethernet、AUTOSAR、车规软件 | 车载软件、域控、中间件、智能驾驶底层 |
| 5. 物联网边缘计算       | 嵌入式 + 云、MQTT、设备上云、边缘网关             | 物联网嵌入式             |
| 6. 嵌入式驱动开发       | Linux 内核驱动、设备树、芯片适配                | 驱动工程师（难度高）         |
| 7. 嵌入式 AI / 机器视觉 | 嵌入式部署模型、YOLO、边缘 AI                 | 边缘 AI、车载感知         |

# 一、堆区内存分配与释放
## 1.malloc/free（c语言）
```cpp
void *malloc(size_t size);
void free(void *ptr);
```
## 2.new/delete单个内存的分配与释放
```cpp
//只分配内存，不初始化
格式：type * p_var = new type;
eg: int *a = new int;
//分配内存，并且进行初始化
格式：type * p_var = new type(value);
eg:int * a =  new int (8);
//释放内存
格式：delete val_ptr;
eg:delete a;
```

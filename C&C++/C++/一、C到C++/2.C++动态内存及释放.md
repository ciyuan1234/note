# 一、堆区内存分配与释放
## 1.malloc/free（c语言）
```cpp
void *malloc(size_t size);
void free(void *ptr);
```
## 2.new/delete单个内存的分配与释放
```cpp
//只分配内存，不初始化
格式：type * p_var = new type;
eg: int *a = new int;
//分配内存，并且进行初始化
格式：type * p_var = new type(value);
eg:int * a =  new int (8);
//释放内存
格式：delete val_ptr;
eg:delete a;
```

##  两个种寻址方式的区别
**==eg：==**  
-  第一种： 
	数组：`int m[] = {1,2,3,4};`
	长度：**4 个元素**
	内存：**一整块连续**
	指针 **永远不动**，站在数组开头，操作**整片内存**。
```cpp
m[0] = 1;
m[1] = 2;
m[2] = 3;
m[3] = 4;
```
- 指针 m **一直指向第一个元素 1**
- 操作的是**整块连续内存**
- 想拿哪个就拿哪个，不会乱
---
- 第二种：
	指针 **自己往前走**，每次**跳过一个元素的内存**。
```cpp
*m = 1;  m++;  // 跳过1，指向2
*m = 2;  m++;  // 跳过2，指向3
*m = 3;  m++;  // 跳过3，指向4
*m = 4;  m++;  // 跳过4，指向数组外面！
```
- 指针 m **一直在移动**
- 每次都**跳过当前元素**，走到下一个
- 最后指针**跑飞了**，找不到数组开头了

# 二、面试常问问题
## 1、有了malloc/free为什么还要new/delete?
- malloc与free是C++/C语言的标准库函数，new/delete是C++的运算符。它们都用于申请动态内存和释放内存。
- 对于非内部数据类型的对象而言，只用malloc/free无法满足动态对象的要求。对象在创建的同时要自动执行构造函数，在对象消亡之前要自动执行析构函数。**构造函数 = 对象出生时自动调用（初始化）**， **析构函数 = 对象死亡时自动调用（清理）**
- 由于malloc是**库函数** 而不是运算符，**不在编译器控制权限之内，不能够把构造函数和析构函数的任务强加于malloc/free，** 因此C++语言需要一个能完成动态内存分配和初始化工作的运算符new，以及一个能完成清晰和释放内存工作的运算符delete。
## 2、既然new/delete的功能完全覆盖了malloc/free，为什么C++不把malloc/free淘汰
- 因为C++程序经常调用C函数，二C程序只能使用malloc/delete管理动态内存
## 3、malloc/free与new/delete之间的区别
- 他们都是动态管理内存的入口
- malloc/free是C/C++标准库的函数，new/delete是C++运算符
- **malloc/free只是动态分配内存空间/释放内存空间，而new/delete除了分配空间还会调用构造函数进行初始化，析构函数进行资源释放**
- malloc/free需要手动计算类型大小且返回值为void*，new/delete科自己计算类型的大小，返回对应类型得指针

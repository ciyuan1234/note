# 一、time函数
## 1.`time(NULL)` 
==**作用：**==获取当前系统时间，返回一个数字（1970-01-01到现在的秒数，时间戳）。
```c
// 1. 获取秒数（电脑用的）
time_t time(time_t *t);
// 2. 翻译成 年-月-日 时:分:秒（人用的）
 struct tm* t = localtime(&now);
 //定义一个字符串来存储时间
 char time_str[64];
 //将时间存储到数组中
 strftime(time_str, sizeof(time_str), "%Y-%m-%d %H:%M:%S", t);
```
### 1. 参数传传递
参数 `t` 是用来**存储时间**的指针。
传 `NULL` = **我不需要你帮我存，我只要返回值**。
### 2. 等价写法（帮助你理解）
```c
time_t now;
time(&now); // 把时间存到 now 里
```
和下面这行**完全一样**：
```c
time_t now = time(NULL);
```
## 2.示例
```c
time_t now = time(NULL);
```
### ① `time_t`
- 是 C 语言专门用来**存时间**的类型
- 本质就是一个**整数**（long / long long）
- 存的是：**从 1970 年 1 月 1 日 到现在的总秒数**
### ② `now`
- 变量名，随便起，比如 `current_time` 也行
- 用来**保存获取到的时间**
### ③ `time(NULL)`
- `time()`：获取系统时间的标准库函数
- 参数传 `NULL`：表示**我只要返回值，不需要别的存储方式**
### ④ 整行意思
**获取当前系统时间戳，存到 now 变量里。**
## 3.返回值
- **成功**：返回一个 `time_t` 类型的**时间戳数字**
- **失败**：返回 `·-1`
```c
time_t now = time(NULL);
```
## 4.头文件
```c
#include <time.h>
```

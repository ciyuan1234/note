# 一、内存四区

程序运行时，内存**永远分成 4 个区域**：

1. **栈区 (Stack)**
2. **堆区 (Heap)**
3. **全局 / 静态区 (Global/Static)**
4. **代码区 (Code)**
---
# 二、四区详细讲解

## 1. 栈区（Stack）

**特点：**

- 由系统自动分配、自动释放
- 存放：**局部变量、函数参数、对象**
- 生命周期：**函数执行完自动销毁**
- 速度最快
```
void test() {
    int a = 10;          // 栈变量
    string str = "123";  // 栈对象
}
// 函数结束 → a、str 全部自动销毁，无需手动释放
```
---
## 2. 堆区（Heap）
**特点：**

- 手动申请、手动释放
- C++ 用 **new / delete**，不再用 malloc/free
- 生命周期由程序员控制
- 不释放会造成**内存泄漏**
```
// 申请堆内存
int* p = new int;        // 申请一个int
int* arr = new int[10];  // 申请数组

// 释放堆内存
delete p;
delete[] arr;   // 数组必须加[]
```

---

## 3. 全局 / 静态区（Data Segment）

**特点：**

- 程序运行期间**一直存在**
- 存放：**全局变量、static 静态变量**
- 自动初始化为 0

```
int g_a = 100;        // 全局变量
static int s_b = 200; // 静态变量

int main() {
    static int s_c = 300; // 静态局部变量
}
```

---

## 4. 代码区（Code）

- 存放程序二进制代码
- 函数体、类的成员函数都在这里
- 只读，不能修改

---
# 三、四区总结（最简单记忆）

1. **栈区**：局部变量，自动释放
2. **堆区**：new/delete 管理，手动释放
3. **全局区**：全局变量、static，程序运行一直存在
4. **代码区**：存放代码，只读

# 一、C++ 内存四区（完全没变！）

程序运行时，内存**永远分成 4 个区域**：

1. **栈区 (Stack)**
2. **堆区 (Heap)**
3. **全局 / 静态区 (Global/Static)**
4. **代码区 (Code)**
---
# 二、四区详细讲解（C++ 版）

## 1. 栈区（Stack）

**特点：**

- 由系统自动分配、自动释放
- 存放：**局部变量、函数参数、对象**
- 生命周期：**函数执行完自动销毁**
- 速度最快
```
void test() {
    int a = 10;          // 栈变量
    string str = "123";  // 栈对象
}
// 函数结束 → a、str 全部自动销毁，无需手动释放
```
---
## 2. 堆区（Heap）
**特点：**

- 手动申请、手动释放
- C++ 用 **new / delete**，不再用 malloc/free
- 生命周期由程序员控制
- 不释放会造成**内存泄漏**
```
// 申请堆内存
int* p = new int;        // 申请一个int
int* arr = new int[10];  // 申请数组

// 释放堆内存
delete p;
delete[] arr;   // 数组必须加[]
```

---

## 3. 全局 / 静态区（Data Segment）

**特点：**

- 程序运行期间**一直存在**
- 存放：**全局变量、static 静态变量**
- 自动初始化为 0

**例子：**

cpp

运行

```
int g_a = 100;        // 全局变量
static int s_b = 200; // 静态变量

int main() {
    static int s_c = 300; // 静态局部变量
}
```

---

## 4. 代码区（Code）

- 存放程序二进制代码
- 函数体、类的成员函数都在这里
- 只读，不能修改

---

# 三、C++ 最核心区别：new /delete 代替 malloc /free

## malloc /free（C 语言）

- 只分配内存，**不调用构造函数**
- 需要强制类型转换
- 需要计算字节数

## new / delete（C++）

- **分配内存 + 调用构造函数**
- **自动类型匹配，不用强转**
- 语法更简洁、更安全

---

# 四、2 个经典例子（彻底懂四区）

## 例子 1：栈区 vs 堆区

cpp

运行

```
#include <iostream>
using namespace std;

int main() {
    // 1. 栈区：自动创建、自动释放
    int a = 10;

    // 2. 堆区：手动创建、手动释放
    int* p = new int(20); // 堆内存赋值 20

    cout << *p << endl;

    delete p;   // 必须手动释放
    p = nullptr;

    return 0;
}
```

---

## 例子 2：C++ 对象的栈与堆（超级重要）

cpp

运行

```
#include <iostream>
using namespace std;

class Person {
public:
    Person() { cout << "构造" << endl; }
    ~Person() { cout << "析构" << endl; }
};

int main() {
    // 栈对象：自动构造 + 自动析构
    Person p1;

    // 堆对象：手动new构造，必须手动delete析构
    Person* p2 = new Person();

    delete p2;  // 不写就不会析构 → 内存泄漏
    p2 = nullptr;

    return 0;
}
```

# 五、四区总结（最简单记忆）

1. **栈区**：局部变量，自动释放
2. **堆区**：new/delete 管理，手动释放
3. **全局区**：全局变量、static，程序运行一直存在
4. **代码区**：存放代码，只读

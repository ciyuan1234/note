## 二、核心功能的场景化用法

### 1. 必用：会话 + 我的会话

- **会话**：所有连接的入口，你之前配置的 SSH、串口、WSL 连接都在这里创建。
- **我的会话**：把常用的开发板、服务器连接保存为书签，下次直接双击打开，不用重复输入 IP / 端口。

### 2. 效率神器：终端分屏

- **典型场景**：同时调试串口和 SSH
    
    1. 打开串口会话，看开发板启动日志；
    2. 点击「终端分屏」，新建一个 SSH 会话，直接在同一个窗口里给开发板发命令；
    3. 不用来回切换窗口，边看日志边调试，效率拉满。
    

### 3. 进阶必备：隧道（SSH 端口转发）

- **场景 1：内网开发板访问**
    
    你的车载开发板在公司内网，你在家可以通过一台跳板机，用本地端口转发，把跳板机的端口映射到开发板，实现远程调试。
- **场景 2：本地访问开发板服务**
    
    开发板上跑了一个 Web 服务（比如调试车载 UI），通过端口转发把开发板的端口映射到本地，直接用浏览器访问。

### 4. 调试辅助：工具

- 用`ping`/`traceroute`排查开发板和电脑的网络连通性；
- 用端口扫描工具检查开发板的 22（SSH）、80（HTTP）端口是否开放，判断服务是否正常启动。

表格

|:--|:--|:--|
|最高|会话 + 我的会话|快速连接所有设备|

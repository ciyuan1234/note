
## 一、工具栏功能对照表
![[Pasted image 20260426110919.png]]

| 按钮       | 核心功能                                      | 你的嵌入式 / 车载 Linux 场景适用性                    |
| :------- | :---------------------------------------- | :---------------------------------------- |
| **会话**   | 创建新的远程 / 本地会话（SSH、串口、Telnet 等，就是你上一张图的界面） | ✅ **最高频使用**，连接开发板、服务器、WSL 都从这里开始          |
| 服务器      | 启动本地服务（如 FTP、SFTP、SSH 服务器），让其他设备连接你的电脑    | ⭕ 仅需临时让开发板 / 其他设备访问你的文件时用，不常用             |
| 工具       | 内置网络工具集：端口扫描、traceroute、ping、nslookup 等   | ✅ 调试网络时用，比如排查开发板和电脑的连通性、端口是否开放            |
| 我的会话     | 快速打开你之前保存过的所有会话（书签）                       | ✅ 非常实用，保存开发板、服务器的连接配置，下次一键打开              |
| 视图       | 调整终端显示样式：字体、颜色、透明度、布局等                    | ⭕ 按需使用，比如调大字体方便看日志                        |
| **终端分屏** | 把一个窗口分成多个终端，同时操作多个会话 / 命令                 | ✅ 调试神器！一边看串口启动日志，一边 SSH 连开发板执行命令，不用来回切换窗口 |
| 多重执行     | 同时在多个打开的终端里执行相同的命令                        | ⭕ 批量管理多台开发板 / 服务器时用，比如给多个设备同步更新程序         |
| 隧道       | 配置 SSH 端口转发（本地 / 远程 / 动态端口转发）             | ✅ 进阶场景用，比如通过跳板机访问内网的车载开发板、把开发板的服务映射到本地    |
| 软件包      | 安装 MobaXterm 的扩展插件 / 工具（如编译器、Git 等）       | ⭕ 可选，本地 Shell 需要额外工具时用                    |
| 设置       | 全局配置：外观、SSH、串口、网络、快捷键等                    | ✅ 首次使用必调，比如设置串口默认波特率、SSH 密钥路径             |
| 帮助       | 打开官方帮助文档                                  | ❌ 用得少，遇到疑难问题时可以查                          |

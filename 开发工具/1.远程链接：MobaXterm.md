
## 一、工具栏功能对照表
![[Pasted image 20260426110919.png]]

| 按钮       | 核心功能                                      | 你的嵌入式 / 车载 Linux 场景适用性                    |
| :------- | :---------------------------------------- | :---------------------------------------- |
| **会话**   | 创建新的远程 / 本地会话（SSH、串口、Telnet 等，就是你上一张图的界面） | ✅ **最高频使用**，连接开发板、服务器、WSL 都从这里开始          |
| 服务器      | 启动本地服务（如 FTP、SFTP、SSH 服务器），让其他设备连接你的电脑    | ⭕ 仅需临时让开发板 / 其他设备访问你的文件时用，不常用             |
| 工具       | 内置网络工具集：端口扫描、traceroute、ping、nslookup 等   | ✅ 调试网络时用，比如排查开发板和电脑的连通性、端口是否开放            |
| 我的会话     | 快速打开你之前保存过的所有会话（书签）                       | ✅ 非常实用，保存开发板、服务器的连接配置，下次一键打开              |
| 视图       | 调整终端显示样式：字体、颜色、透明度、布局等                    | ⭕ 按需使用，比如调大字体方便看日志                        |
| **终端分屏** | 把一个窗口分成多个终端，同时操作多个会话 / 命令                 | ✅ 调试神器！一边看串口启动日志，一边 SSH 连开发板执行命令，不用来回切换窗口 |
| 多重执行     | 同时在多个打开的终端里执行相同的命令                        | ⭕ 批量管理多台开发板 / 服务器时用，比如给多个设备同步更新程序         |
| 隧道       | 配置 SSH 端口转发（本地 / 远程 / 动态端口转发）             | ✅ 进阶场景用，比如通过跳板机访问内网的车载开发板、把开发板的服务映射到本地    |
| 软件包      | 安装 MobaXterm 的扩展插件 / 工具（如编译器、Git 等）       | ⭕ 可选，本地 Shell 需要额外工具时用                    |
| 设置       | 全局配置：外观、SSH、串口、网络、快捷键等                    | ✅ 首次使用必调，比如设置串口默认波特率、SSH 密钥路径             |
| 帮助       | 打开官方帮助文档                                  | ❌ 用得少，遇到疑难问题时可以查                          |

|优先级|功能|用途|
|:--|:--|:--|
|最高|会话 + 我的会话|快速连接所有设备|
|高|终端分屏 + 设置|多窗口调试、配置环境|
|中|隧道 + 工具|远程访问、网络调试|
|低|其他|按需使用|
## 二、各会话类型核心用途与场景适配
![[Pasted image 20260426112258.png]]

| 会话类型     | 核心功能                      | 安全性      | 你的场景适配度     | 典型用法                                  |
| :------- | :------------------------ | :------- | :---------- | :------------------------------------ |
| **SSH**  | 加密远程登录 Linux 设备，执行命令、传输文件 | 高（全链路加密） | ✅ 必用        | 连接车载开发板、云服务器、WSL，调试 Linux 程序          |
| Telnet   | 明文远程登录协议                  | 极低（明文传输） | ❌ 淘汰协议      | 仅老旧设备调试用，不推荐                          |
| Rsh      | 明文远程命令执行工具                | 极低（明文传输） | ❌ 已被 SSH 替代 | 几乎不用                                  |
| Xdmcp    | Linux 图形界面远程显示协议          | 低        | ❌ 已被 VNC 替代 | 几乎不用                                  |
| **RDP**  | Windows 远程桌面协议            | 中        | ⭕ 低频使用      | 远程控制 Windows 主机，比如在公司内网调试 Windows 上位机 |
| VNC      | 跨平台远程图形界面（Linux/Windows）  | 中        | ⭕ 按需使用      | 调试带 Qt/GTK 图形界面的嵌入式 Linux 设备（如车载中控）   |
| FTP      | 明文文件传输协议                  | 极低       | ❌ 明文不安全     | 仅老旧设备临时传文件用，优先用 SFTP                  |
| **SFTP** | 基于 SSH 的加密文件传输            | 高        | ✅ 高频使用      | 给开发板上传 / 下载代码、日志文件，配合 SSH 使用          |
| **串口**   | 本地 UART 串口连接，调试嵌入式设备      | 高（本地直连）  | ✅ 核心必备      | 查看开发板启动日志、调试裸机 / RTOS 程序、无网环境交互       |
| 文件       | 本地文件管理器                   | -        | ⭕ 辅助使用      | 快速访问本地文件，拖拽文件到远程会话                    |
| Shell    | 内置本地 Linux 终端（Cygwin 环境）  | -        | ✅ 高频使用      | 本地练习 Linux 命令、编译工具链、运行脚本              |
| 浏览器      | 内置简易浏览器                   | -        | ❌ 鸡肋功能      | 几乎不用                                  |
| Mosh     | 弱网环境下的 SSH 替代方案           | 高        | ⭕ 特殊场景      | 网络不稳定时连接远程开发板 / 服务器                   |
| Aws S3   | 亚马逊云存储连接                  | -        | ❌ 无关场景      | 无 AWS 服务时不用                           |
| **WSL**  | 直接连接 Windows 上的 WSL 环境    | -        | ✅ 高频使用      | 本地搭建交叉编译环境，编译内核 / 应用再推送到开发板           |

---
### 1. 最高频：SSH + 串口（嵌入式开发双核心）

#### SSH 会话

- **配置步骤**：输入开发板 IP、端口（默认 22）、用户名密码，或配置 SSH 密钥免密登录
- **核心用法**：远程执行 Linux 命令、调试程序、查看系统日志，连接后自动弹出 SFTP 文件传输窗口
- **进阶技巧**：配置会话保存，下次双击直接连接；使用 SSH 隧道穿透访问内网开发板

#### 串口会话

- **配置步骤**：用 USB 转 TTL 连接开发板 UART，在设备管理器查看 COM 号，配置波特率（如 115200）、数据位 / 停止位 / 校验位（8N1）
- **核心用法**：查看 Bootloader / 内核启动日志、无网环境下给开发板设置 IP、调试串口驱动 / 裸机程序
- **避坑提示**：波特率必须和设备配置一致，否则会出现乱码；不要同时用多个串口工具打开同一个 COM 口

### 2. 高频辅助：SFTP + WSL + Shell

#### SFTP 会话

- 优先配合 SSH 使用，也可单独创建会话，直接在本地和开发板间拖拽文件，传输速度快且加密
- 适合批量上传代码、下载设备日志，比命令行`scp`更直观

#### WSL 会话

- 直接连接 Windows 上的 WSL 环境，无需配置 IP，在 WSL 中搭建交叉编译环境、编译嵌入式 Linux 内核 / 应用，再通过 SSH/SFTP 推送到开发板
- 适合本地开发调试，不用额外安装虚拟机

#### Shell 会话

- 内置类 Linux 终端，可直接练习`gcc`编译、`make`构建、`git`操作，或运行简单脚本
- 适合嵌入式 Linux 开发前期的命令基础练习，不用额外安装 Cygwin

### 3. 低频场景：VNC/RDP

#### VNC 会话

- 当你的嵌入式 Linux 设备带图形界面（如带 Qt 的车载中控系统），可通过 VNC 远程查看和操作图形界面，调试 UI 程序
- 配置时需先在开发板上安装 VNC 服务端，再通过 MobaXterm 的 VNC 会话连接

#### RDP 会话

- 仅需远程控制 Windows 主机时使用，嵌入式开发场景几乎用不到，除非需要远程操作 Windows 上位机工具
